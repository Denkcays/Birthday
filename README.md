# Birthday.exe

Небольшой статический сайт-поздравление на чистом HTML, CSS и JavaScript. Адаптирован для компьютеров, планшетов и телефонов.

## Запуск

Открой `index.html` в браузере. Для разработки можно использовать Live Server в VS Code.

## Структура

- `index.html` — тексты, секции, карточки и сертификат.
- `css/style.css` — основное оформление.
- `css/responsive.css` — адаптация под планшеты и телефоны.
- `css/animations.css` — анимации и уважение системной настройки reduced motion.
- `js/` — стартовый экран, появление блоков и безопасный шуточный сюрприз.
- `assets/photos/` — изображения проекта.

## Изображения

Фотографии хранятся в WebP для уменьшения размера загрузки. Анимированная картинка `shunya.gif` оставлена в GIF, чтобы сохранить анимацию.

Чтобы добавить изображение, положи файл в `assets/photos/` и укажи его путь в `src` у нужного тега `<img>`. Для фотографий предпочтителен WebP; GIF используй только если нужна анимация.

## Публикация

Это статический сайт: backend и сборка не нужны. Его можно разместить на GitHub Pages или Cloudflare Pages.
